# Vivek Kumar - Portfolio

Personal portfolio website for Vivek Kumar, a Computer Science and Engineering student and aspiring full stack developer. The site presents his skills, projects, Android application training, certifications, education, resume, and contact details in a responsive single-page experience.

## Features

- Responsive portfolio layout for desktop and mobile screens
- About, skills, projects, training, certifications, education, and contact sections
- Project filtering by Full Stack, AI, Monitoring, and Android categories
- Dark and light theme toggle with local storage persistence
- Mobile navigation menu
- Downloadable and viewable CV
- Client-side contact form validation with demo feedback
- GitHub, LinkedIn, and email links

## Featured Projects

### Smart Clinic

Appointment and queue management system built with React.js, Node.js, Express.js, MongoDB, Socket.io, and JWT. It supports appointment booking, patient management, real-time queue tracking, notifications, and authenticated access.

### DiskWatch

Real-time disk space and storage health monitor built with Python, Flask, and SQLite. It provides multi-drive monitoring, threshold-based alerts, live polling, and rapid reporting of critical changes.

### Flight

AI-powered flight search and price tracking platform built with Next.js, Tailwind CSS, Framer Motion, and multiple AI providers. SkyBot enables natural-language flight search, comparison, and recommendations.

### Medical Reminder App

Offline-first Android medicine reminder application built with Kotlin and MVVM. It uses Room, LiveData, Coroutines, AlarmManager, BroadcastReceiver, and NotificationManager for scheduling, adherence tracking, and reboot-persistent reminders.

## Tech Stack

This portfolio itself is a static website built with semantic HTML, CSS, and vanilla JavaScript. It uses Google Fonts for typography and has no build step or package dependencies.

## Run Locally

1. Clone the repository:

	```bash
	git clone https://github.com/Mrvivek99/vivek-kumar-portfolio.git
	cd vivek-kumar-portfolio
	```

2. Open `portfolio.html` in a browser.

	For local development, the folder can also be served with any static file server, such as VS Code Live Server.
